# Changelog

## 0.5.1 — 2026-07-11

### Исправления

- Мастер-порт больше не сбрасывается в Off при переключении на другой сервер во время активной сессии. Раньше переключение пересоздавало слушатель на том же порту; при живых соединениях повторный bind падал с «Address already in use», и выбор молча сбрасывался. Теперь слушатель не пересоздаётся — существующий прокси перенаправляется на новую цель (активные соединения по-прежнему разрываются, трафик сразу идёт через новый сервер).

### Обновление

Выйти из работающего SSH Manager (Quit) → установить pkg поверх → запустить. Конфиг, история и логи сохраняются.

## 0.5.0 — 2026-07-02

### Мастер-порт

Один фиксированный локальный порт (по умолчанию 1080), за которым живёт «текущий» SOCKS-туннель. Клиенты настраиваются на него один раз, сервер за портом переключается одним кликом:

- подменю **Master Port :1080 → …** в статус-меню и панель **Master port** в окне управления (там же меняется сам порт, с валидацией);
- при переключении активные соединения через мастер-порт разрываются — трафик сразу идёт через новый сервер;
- выбранный туннель автоматически поднимается, если был остановлен;
- выбор и порт сохраняются в config.json и переживают перезапуск.

### Debug-режим и отчёт

Для диагностики проблем без доступа к машине:

- **Debug Mode** (статус-меню) — трассировка пути трафика в `logs/<id>.trace.log`: accept'ы прокси, чанки байтов, итоги по соединениям, публикация счётчиков. Действует до перезапуска приложения, при выключенном режиме накладных расходов нет;
- **Save Debug Report…** — выгрузка внутреннего состояния одним текстовым файлом: состояния движков, счётчики, планы туннелей, pid ssh-процессов, `lsof` по задействованным портам, хвосты логов. Отчёты складываются в `debug-reports/`;
- всегда включённые диагностические счётчики прокси (принято соединений, активных, срабатываний счётчика байт) — попадают в отчёт даже без Debug Mode.

### Иконка приложения

У приложения появилась иконка (Finder, Spotlight, список приложений). Генерируется из `app_icon.png` скриптом `scripts/make-icon.sh`.

### Формат конфига

`config.json` теперь объект `{masterPort, masterConnectionId, connections}` вместо голого массива. Старый формат мигрирует автоматически при первом запуске — ничего делать не нужно.

### Обновление

Выйти из работающего SSH Manager (Quit) → установить pkg поверх → запустить. Конфиг, история и логи сохраняются.

## 0.1.0 – 0.4.0
